# JA→EN Live Subs Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement the whisper.cpp slice→translate→overlay engine inside the scaffolded IINA plugin so JA video (local + stream) shows EN subs.

**Architecture:** Split `main.js` into small `require()`able `lib/` modules with pure, node-testable functions (command builders, parsers, dedup); `main.js` keeps only per-player wiring. Short-lived `utils.exec` calls only, max 1 in-flight job.

**Tech Stack:** IINA plugin JS (JavaScriptCore, ES2015-safe), whisper.cpp + ffmpeg binaries (external, documented), node (syntax + unit harness only, never shipped).

**Spec:** `docs/superpowers/specs/2026-10-13-ja-en-subs-design.md`

## Global Constraints

- JavaScriptCore ES2015-safe code, no Node APIs, no `fetch`/`window`/`localStorage` in plugin code.
- `Info.json` keeps `file-system` permission (required by `utils.exec`); permissions list otherwise unchanged.
- All transcription state per main-entry instance; `@tmp` filenames include player tag.
- Max 1 in-flight ffmpeg/whisper job per player; short-lived exec only (no daemons — API has no kill).
- Audio never leaves device; `http` only for first-run model download.
- Overlay messages via `postMessage(name, data)` with JSON-serializable data only.
- Frequent commits; each task ends testable.

## Review Focus

- Corrupt/empty whisper JSON output → window skipped silently, loop continues (never stuck `busy`).
- Rapid seeks mid-transcribe → stale result discarded (window id check), overlay cleared once.
- HLS stream that rejects `-ss` → degrades to live-edge without retry storm (fail counter + standby).
- 2-hour video → `@tmp` capped at 4 segs, SRT incrementally flushed, no memory growth.
- Binaries missing/quarantined → one OSD per minute max, menu shows setup state, loop idle.
